# Specification

[`SPEC.md`](SPEC.md) is the **single source of truth** for what every language implementation must do.

- **Draft status:** revision **0.4.0** is a normative proposal. Sections marked **Open** or **Deferred** are not required yet. §12.4 proposes how to add functions; §17 records use cases, corner cases, and existing engines.
- **Versioning:** the spec carries a `Status` and `Revision` at the top; implementations should cite which revision they target.
- **Changes:** debate in [issue #4](https://github.com/manishsharma004/excel-formula/issues/4), then PRs that update `SPEC.md` and reference that issue.
